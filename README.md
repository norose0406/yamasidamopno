# やまなしだもの 結 musubi — サイトリニューアル

https://mb-musubi.net/ の作り直し。食べチョクのようなマーケットプレイス型の配置にした静的サイトです（HTML / CSS / JavaScript のみ、ビルド不要）。

## 構成（上から）

1. お知らせバー
2. ヘッダー：ロゴ／商品検索／お知らせ・マイページ・カート
3. カテゴリアイコン列（桃・ぶどう・コンポート・とうもろこし・キウイ）
4. メインバナー（カルーセル、自動送り）
5. いまが旬のおすすめ（横スクロール、今月が旬のカテゴリを優先表示）
6. おすすめピックアップ
7. 特集バナー
8. つくり手・お店のこと
9. すべての商品（カテゴリで絞り込み）
10. 旬のカレンダー（今月をハイライト）
11. お知らせ
12. ご利用ガイド
13. 多段フッター ＋ スマホ用ボトムナビ

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの骨組み |
| `css/style.css` | デザイン（スマホ対応） |
| `js/data.js` | **商品・お知らせ・バナー・リンクのデータ。更新はここだけ** |
| `js/main.js` | 描画・検索・絞り込み・カルーセル |

購入・決済は既存のカラーミーショップをそのまま使います。各商品カードは現行の商品ページ（`?pid=...`）にリンクしています。

## 写真の入れ方

写真がない間は、カテゴリ色の上品なプレースホルダー（Peach / Grape …）を表示します。

**方法A：現行ショップの写真をそのまま使う（おすすめ・1行で完了）**
1. 現行サイト https://mb-musubi.net/ の商品写真を右クリック →「画像アドレスをコピー」
   （`https://imgXX.shop-pro.jp/PAxxxxxxxx/xxx/product/169870083.jpg?...` のような形）
2. `js/data.js` の `imageBase` に `/product/` までを貼り付け
   ```js
   imageBase: "https://imgXX.shop-pro.jp/PAxxxxxxxx/xxx/product/",
   ```
3. 全商品・バナー・特集・カテゴリアイコンに、商品IDに対応した写真が表示されます

**方法B：画像ファイルを置く**
`images/` フォルダに写真を置き、各商品・バナーの `image` に `"images/xxx.jpg"` を指定します。
「つくり手・お店のこと」の写真は `storyImage` で指定できます（未指定ならバナー1枚目の写真）。
