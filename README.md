# Chrome View

ブラウザのサイドパネルで、今見ているタブの情報を表示する Chrome 拡張機能（Manifest V3）です。

## 機能

- ツールバーのアイコンをクリックすると、サイドパネルにビューが開く
- 現在のタブのタイトル・URL・ファビコンを表示（URLはコピーできる）
- 同じウィンドウのタブ一覧を表示（クリックするとそのタブに切り替わる）
- タブを切り替えたり、開いたり閉じたりすると表示が自動で更新される
- ライトモードとダークモードの両方に対応

## インストール方法

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリの `extension/` フォルダを選ぶ
4. ツールバーの拡張機能アイコン（パズルのピース）から「Chrome View」をピン留めし、クリックする

※ サイドパネルを使うには Chrome 114 以降が必要です。

## 構成

```
extension/
├── manifest.json    # 拡張機能の設定
├── background.js    # アイコンをクリックしたらサイドパネルを開く
├── sidepanel.html   # ビューの画面
├── sidepanel.css
├── sidepanel.js     # タブ情報の取得と表示
└── icons/
```
