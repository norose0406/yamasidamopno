# やまなしだもの 結 musubi — サイトリニューアル

https://mb-musubi.net/ の作り直し。食べチョクのようなマーケットプレイス型の配置にした静的サイトです（HTML / CSS / JavaScript のみ、ビルド不要）。

## 構成（上から）

1. お知らせバー
2. ヘッダー：ロゴ／商品検索／お知らせ・マイページ・カート
3. カテゴリアイコン列（桃・ぶどう・コンポート・とうもろこし・キウイ）
4. メインバナー（カルーセル、自動送り）
5. いまが旬のおすすめ（横スクロール、今月が旬のカテゴリを優先表示）
6. おすすめピックアップ
7. 特集バナー
8. つくり手・お店のこと
9. すべての商品（カテゴリで絞り込み）
10. 旬のカレンダー（今月をハイライト）
11. お知らせ
12. ご利用ガイド
13. 多段フッター ＋ スマホ用ボトムナビ

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの骨組み |
| `css/style.css` | デザイン（スマホ対応） |
| `js/data.js` | **商品・お知らせ・バナー・リンクのデータ。更新はここだけ** |
| `js/main.js` | 描画・検索・絞り込み・カルーセル |

購入・決済は既存のカラーミーショップをそのまま使います。各商品カードは現行の商品ページ（`?pid=...`）にリンクしています。

## 確認・差し替えが必要な項目（TODO）

作業環境から現行サイトに直接アクセスできなかったため、検索エンジンに載っている情報だけで作っています。以下は公開前に確認してください。

- `js/data.js` の `links`：カート・マイページ・特商法・プライバシーポリシー・お問い合わせの URL
- 商品の価格：確認できた2点（3種詰め合わせ ¥5,940、キウイ6パック ¥4,860）以外は `null`（「価格は商品ページで」表示）
- 商品の販売状況（`status`）とピックアップの順番（`pickup`）
- お知らせの正確な日付
- 旬カレンダーの月（`categories[].months`）
- 商品写真：現在はイラスト（絵文字）で代用。写真を入れる場合は `main.js` の `card()` で `<img>` に差し替え

## ローカルで見る

`index.html` をブラウザで開くだけで表示できます。
