# 月30件の問い合わせ・受注に向けた集客プラン（MEO・SEO・SNS）

このサイトは「問い合わせ」と「注文の申し込み」を増やすことを目的に作っています。
ここでは、公開前に設定すること、公開後に続けることをまとめます。

## 1. 目標の考え方

| 指標 | 目安 |
| --- | --- |
| 問い合わせ＋注文の申し込み | 月30件 |
| 問い合わせ率（訪問者のうち問い合わせる人） | 1〜2%（一般的な目安。実際の数字は GA4 で計測して見直す） |
| 必要な訪問数 | 月1,500〜3,000訪問 |

訪問の入り口は「Googleマップ（MEO）」「Google検索（SEO）」「SNS」の3つです。
問い合わせが増えやすいのは、旬の直前（予約開始）とギフトシーズン（お中元：6〜7月、お歳暮：11〜12月）です。

## 2. 公開前に設定すること（`js/config.js`）

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| `siteUrl` | サイトを公開するURL。canonical・OGP・サイトマップに使う | 仮に `https://mb-musubi.net` を入れています。別のドメインで公開する場合は必ず変更 |
| `inquiry.endpoint` | 問い合わせ・注文申し込みの送信先 | 未設定（今はメールアプリが開く方式）。Formspree などを使うとサイト上で送信が完結し、取りこぼしが減ります |
| `analytics.ga4Id` | Googleアナリティクス4 の測定ID | 未設定。入れると問い合わせ数を自動で計測できます |
| `meo.reviewUrl` | Googleの「クチコミを書く」リンク | 未設定。入れると店舗情報にボタンが出ます |
| `sns.line` | LINE公式アカウントの友だち追加URL | 未設定。入れると問い合わせ欄とSNS欄にLINEが出ます |

変更したら `npm run build` を実行して、商品ページ・サイトマップを作り直してください。

## 3. MEO（Googleマップ）

サイト側の対応：店舗情報（名前・住所・電話）を特定商取引法の表記と同じ書き方で掲載し、検索エンジン向けのデータ（Store）と地図を入れています。

続けること：

1. **Googleビジネスプロフィールを登録・確認**（甲府市下石田2-14-8）。店名・住所・電話はサイトと一字一句同じにする。
2. ウェブサイト欄にこのサイトのURLを入れる。計測のため `?utm_source=google&utm_medium=organic&utm_campaign=gbp` を付ける。
3. **写真を週1回以上追加**（畑・収穫・箱詰め・商品）。
4. **投稿を週1回**（予約開始、収穫状況、ギフトのご案内）。
5. **クチコミを集める**：発送する箱にクチコミ用のQRコードを入れる。もらったクチコミにはすべて返信する。

## 4. SEO（Google検索）

サイト側の対応：

- 商品ごとのページ（`products/*.html`）に、それぞれのタイトル・説明・SNS共有用の画像・商品データ（Product）を設定
- トップに店舗・よくある質問・商品一覧のデータ（Store・FAQPage・ItemList）
- `sitemap.xml` と `robots.txt`

続けること：

1. **Google Search Console** にサイトを登録し、`sitemap.xml` を送信する。
2. 狙うキーワードの例（商品ページのタイトル・説明文に反映済み）：
   - 「シャインマスカット 通販 山梨」「山梨 ぶどう 産地直送」「種なし巨峰 通販」
   - 「追熟キウイ 通販」「香緑 キウイ」「甘々娘 とうもろこし 通販」「ピュアホワイト 通販」
   - 「お歳暮 果物 山梨」「法人 ギフト 果物」
3. **旬の2か月前に商品ページを更新**（予約開始の告知、在庫数）。検索の評価が上がるまで時間がかかるため。
4. 生産者の話や食べ方などの記事を増やすと、検索からの入り口が増えます（次の改善候補）。

## 5. SNS

サイト側の対応：

- 各ページのSNS共有用の情報（OGP）、商品詳細のシェアボタン（LINE・X・Facebook・リンクのコピー）
- 「結 musubi について」欄のフォローボタン、フッターのSNSリンク
- 商品ごとの直接リンク（`#item-商品ID` と `products/商品ID.html`）。投稿にそのまま貼れます

続けること：

| SNS | 内容 | 頻度 |
| --- | --- | --- |
| Instagram（@musubi_yamanashi） | 収穫・箱詰めのリール、ストーリーズに商品リンク | 週3回 |
| X（@mb_renecs） | 予約開始・入荷・残りわずかのお知らせ | 動きがあるたび |
| YouTube | 畑や収穫のショート動画 | 月2回 |
| Facebook | 地元・法人向けのギフト案内 | 月2回 |
| LINE公式（新規） | リピーターへの予約開始の通知 | シーズンごと |

プロフィールや投稿のリンクには `?utm_source=instagram&utm_medium=social` のように付けると、どのSNSから問い合わせが来たかが分かります。

## 6. 計測（GA4 に送るイベント）

`analytics.ga4Id` を設定すると、次のイベントが送られます。GA4 で `generate_lead` を「キーイベント」に設定すると、問い合わせ数を毎月追えます。

| イベント | 発生するとき |
| --- | --- |
| `generate_lead` | 問い合わせの送信（lead_type=inquiry）、注文の申し込み（lead_type=order） |
| `click_tel` / `click_email` | 電話・メールのリンクを押した |
| `click_store` | 公式オンラインショップ（カラーミー）で購入するリンクを押した |
| `view_item` / `add_to_cart` / `begin_checkout` | 商品を見た／カートに入れた／注文手続きを始めた |
| `add_to_wishlist` / `share` / `click_sns` / `search` | お気に入り・シェア・SNSのクリック・検索 |

## 7. 毎月の振り返り

1. 問い合わせ＋申し込みの件数（`generate_lead`）と、入り口（Googleマップ・検索・SNS）の内訳を見る
2. よく見られている商品・見られているのに問い合わせが少ない商品を見る
3. 翌月の旬・ギフトシーズンに合わせて、投稿と商品ページを先回りで更新する
