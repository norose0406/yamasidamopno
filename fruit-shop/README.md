# 甲斐のくだもの便（山梨フルーツECサイト）

山梨県産の桃・ぶどう・すもも・さくらんぼ・ころ柿などを販売するECサイトのデモです。
HTML / CSS / JavaScript だけで作っていて、ビルドやサーバーは要りません。

## 使い方

`fruit-shop/index.html` をブラウザで開くだけで動きます。
（GitHub Pages などの静的ホスティングにそのまま置くこともできます）

## 機能

- 商品一覧：カテゴリ絞り込み、キーワード検索、並び替え（価格・旬が近い順）、「今すぐ届く商品のみ」表示
- 旬に合わせた販売状況：旬の商品は「販売中」、旬以外は「予約受付中」、在庫5点以下は「残りわずか」
- 商品詳細：内容量・産地・旬の時期・配送方法（クール便／常温便）、数量を選んでカートへ
- カート：数量変更・削除、送料無料までの残り金額、ブラウザに保存（再読み込みしても残る）
- ご注文手続き：お届け先、お届け日（3日後〜30日後）・時間帯、支払い方法、のし・ギフト包装
  - 入力チェック（全角数字の郵便番号・電話番号も受け付け）
- 旬カレンダー、ご利用ガイド
- スマートフォン対応、ライトモード／ダークモード対応

※ デモのため、実際の注文・決済・メール送信は行いません。

## 構成

```
fruit-shop/
├── index.html
├── css/style.css
├── js/
│   ├── products.js       # 商品データ（価格・旬・在庫など）
│   ├── shop.js           # 価格計算・旬の判定・入力チェック（画面に依存しない）
│   ├── illustrations.js  # 果物のイラスト（SVG）
│   └── app.js            # 画面の表示と操作
└── tests/shop.test.js
```

商品を追加・変更するときは `js/products.js` を編集してください。

## テスト

```
node --test fruit-shop/tests/shop.test.js
```
