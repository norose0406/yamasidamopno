# やまなしだもの 結 musubi（山梨フルーツECサイト）

[やまなしだもの 結 musubi](https://mb-musubi.net/) の取り扱い商品（ぶどう・詰め合わせ・追熟キウイ「やまなしの雫」・朝採りとうもろこし）をもとにした、ECサイトのデモです。
HTML / CSS / JavaScript だけで作っていて、ビルドやサーバーは要りません。

## 使い方

### ローカルサーバーで見る（おすすめ）

Node.js（18以上）が入っていれば、リポジトリのフォルダで次を実行します。追加のインストールは要りません。

```
git clone https://github.com/norose0406/yamasidamopno.git
cd yamasidamopno
git checkout claude/adoring-brahmagupta-yjazml
npm start
```

ブラウザで http://localhost:8080 を開いてください。止めるときは `Ctrl + C` です。

- ポートを変える: `PORT=3000 npm start`
- 同じWi-Fiのスマホから見る: `HOST=0.0.0.0 npm start` で起動し、スマホで `http://<PCのIPアドレス>:8080` を開く

### ファイルを直接開く

`fruit-shop/index.html` をダブルクリックしてブラウザで開くだけでも動きます。
（GitHub Pages などの静的ホスティングにそのまま置くこともできます）

## 機能

- 商品写真：mb-musubi.net の商品写真・スライド写真を表示（画像サーバー `img21.shop-pro.jp` から直接読み込み）。読み込めないときはイラストに切り替わる
- サイズ選択：2kg / 4kg、3パック / 6パック などのサイズ違いを1つの商品として表示
- 商品一覧：カテゴリ絞り込み、キーワード検索、並び替え（価格・旬が近い順）、「今すぐ届く商品のみ」表示
- 旬に合わせた販売状況：旬の商品は「販売中」、旬以外は「予約受付中」、在庫5点以下は「残りわずか」、在庫0は「売り切れ」（一覧の最後に表示）
- 商品詳細：産地・発送目安・配送方法（クール便／常温便）、サイズと数量を選んでカートへ
- カート：数量変更・削除、送料無料までの残り金額、ブラウザに保存（再読み込みしても残る）
- ご注文手続き：お届け先、お届け日（3日後〜30日後）・時間帯、支払い方法、のし・ギフト包装
  - 入力チェック（全角数字の郵便番号・電話番号も受け付け）
- 旬カレンダー、ご利用ガイド
- スマートフォン対応、ライトモード／ダークモード対応

※ デモのため、実際の注文・決済・メール送信は行いません。
※ 商品名・価格・説明・発送目安・在庫状況は mb-musubi.net の掲載内容（2026年10月時点）をもとにしています。送料・手数料はデモ用の仮の金額です。

## 構成

```
fruit-shop/
├── index.html
├── server.js             # ローカル確認用サーバー（npm start）
├── css/style.css
├── js/
│   ├── products.js       # 商品データ（価格・サイズ・旬・在庫・写真URLなど）
│   ├── shop.js           # 価格計算・旬の判定・入力チェック（画面に依存しない）
│   ├── illustrations.js  # 果物のイラスト（SVG）
│   └── app.js            # 画面の表示と操作
└── tests/shop.test.js
```

商品を追加・変更するときは `js/products.js` を編集してください。
